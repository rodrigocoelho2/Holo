# Screenshots do Dashboard TcgStockBot

Esta pasta contém exemplos visuais do dashboard do TcgStockBot.

## Imagens esperadas:

### `dashboard-overview.png`
Screenshot da página "Visão Geral" mostrando:
- Resumo de alertas (68 alertas)
- Gráfico de 14 dias
- Estatísticas por loja

### `dashboard-tasks.png`
Screenshot da página "Tarefas" mostrando:
- Lista de produtos monitorados

Screenshot da página "Lojas" mostrando:

- Últimas verificações

## Como adicionar as imagens:

1. Captura a screenshot do dashboard
2. **Remove informações sensíveis** (URLs internas, IPs, portas específicas, emails, telefones, etc.)
3. Salva como PNG na pasta com o nome apropriado
4. Faz commit e push

## Nota de Segurança:

⚠️ **Nunca commites screenshots com:**
- Emails reais
- Números de telefone
- IPs da rede local
- Nomes de utilizadores
- Tokens ou API keys
- Dados pessoais
- Qualquer informação sensível

Se precisas de borrar partes de uma imagem:
- Usa ferramentas como Paint, GIMP, ou https://www.pixlr.com/
- Coloca retângulos pretos ou borra as áreas sensíveis
